변경 이력

p4-web은 Perforce로 개발됩니다 — 아래 항목은 모두 실제로 서브밋된 체인지리스트이며 최신순입니다. 소스는 GitHub에 미러링됩니다.

목록은 계속 이어지고, 그림은 그림으로 열립니다

  • 67389체인지리스트에서 이미지를 누르면 다운로드가 시작되는 대신 파일 뷰어에서 바로 열립니다 (Perforce에서 .jpg는 binary+F라 다른 바이너리와 함께 다운로드 경로로 갔습니다. 휴대폰에서는 그림을 보기 전에 저장/열기 시트를 먼저 닫아야 했다는 뜻입니다. 뷰어는 원래 이미지를 인라인으로 보여주고 있었고, 원본이 필요하면 뷰어 안의 Raw·Download가 그대로 있습니다. 이미지가 아닌 바이너리는 종전대로 내려받습니다)
  • 67388Changes 목록이 Load more 버튼에서 멈추지 않고 스크롤을 따라 계속 이어집니다 (바닥에 닿기 한 화면쯤 전에 다음 페이지가 도착하기 시작합니다. 빠른 색인도 이제 페이지를 넘길 수 있어서 필터를 건 검색도 첫 200줄에서 끊기지 않습니다. 스스로 굴러가면 곤란한 두 경우 — 실패한 페이지, 그리고 빈 페이지가 연달아 나올 만큼 드문 필터 — 에는 버튼이 다시 나타납니다)

기능을 켜고 끄기

  • 66854상단바 톱니 아이콘에 설정 페이지가 생겼습니다 — 리뷰·코멘트·멘션·쓰기 작업·즐겨찾기·빠른 체인지 검색을 내 계정 기준으로 끌 수 있고, 테마·diff 레이아웃·마크다운 보기도 같은 자리에서 고릅니다 (기능 스위치는 계정에 저장되어 어느 브라우저에서든 따라옵니다. 표시 취향은 기기별로 남는데, 휴대폰은 다크·데스크톱은 라이트가 자연스러운 반면 "여기선 코멘트가 보이고 저기선 안 보인다"는 혼란스럽기 때문입니다)
  • 66852꺼진 기능은 눌러도 실패할 버튼을 남기는 대신 화면에서 사라집니다 — 메뉴 항목, 코멘트 패널과 diff 안 코멘트 버튼, 리뷰 바, 멘션 배지, 즐겨찾기 별, 파일 페이지의 Edit/Delete가 모두 스위치를 따릅니다 (꺼진 기능으로 향하는 링크·북마크도 그대로 열리며, 서버가 껐는지 내 설정이 껐는지 알려줍니다. 변경 전부터 열려 있던 탭은 조용히 실패하는 대신 새로고침을 안내합니다)
  • 66849서버를 운영하는 쪽은 여섯 기능 중 무엇이든 전체에 대해 끌 수 있습니다 — features.json 또는 P4WEB_FEATURE_* 환경변수를 씁니다 (꺼진 기능은 엔드포인트도 응답하지 않으므로 숨긴 버튼이 아니라 실제 경계입니다. 데이터는 지우지 않습니다 — 켜져 있는 동안 쓰인 리뷰·코멘트는 다시 켜면 그대로 돌아옵니다. 배포처마다 사정이 다릅니다: 순수 열람용으로 띄우고 싶은 곳도, 리뷰는 이미 다른 도구가 맡은 팀도 있으니까요)

  • 66477diff의 ---/+++ 머리 두 줄이 다시 헤더로 표시됩니다 — 0번 줄로 번호가 붙은 빨강·초록 편집 줄처럼 보이던 문제입니다
  • 66476휴대폰에서 화면을 당겼을 때 배경이 바깥까지 채워지고, 옆으로 스크롤한 diff의 초록·빨강이 줄 끝까지 이어집니다 (페이지 배경을 문서 루트로 옮기고, 통합 diff 행 폭을 창이 아니라 가장 긴 줄에 맞췄습니다)
  • 66472체인지리스트 안에서 펼친 diff가 휴대폰 화면 밖으로 파일 목록을 늘리지 않습니다 (셀은 표의 폭을 따르고 코드는 원래 의도대로 diff 안에서만 스크롤됩니다. 코멘트 패널은 스크롤해도 제자리에 남습니다)
  • 66471코멘트에서 @이름을 쓰면 그 사람 상단바에 배지가 뜨고, 자신이 언급된 코멘트 목록으로 이어집니다 (실제 Perforce 사용자만 인식하고 입력 중 자동완성됩니다. Changes 목록과 디팟 브라우저에도 체인지·파일별 코멘트 스레드 수와 미해결 수가 표시됩니다)
  • 66470diff 안에서 바로 그 줄에 코멘트를 답니다 — 모든 diff 줄이 앵커를 갖고, 통합 보기에도 드디어 줄번호가 표시됩니다 (체인지리스트 diff에서 연 스레드가 해당 파일 페이지에서도 보이고 그 반대도 마찬가지입니다. 이미 스레드가 있는 줄에는 개수가 표시됩니다)
  • 66468라이트 리뷰: 체인지리스트에 리뷰 중·승인·보완 필요 상태를 달고, 누가 언제 왜 바꿨는지 이력으로 남깁니다 (More 메뉴의 새 Reviews 페이지에서 모아 봅니다. 체인지리스트 자체는 아무것도 바뀌지 않고 상태는 코멘트 옆에 저장됩니다)
  • 66465가이드에 폴더 diff 단계를 추가했습니다 — 디렉토리 전체를 다른 경로와, 또는 예전 체인지리스트·날짜 시점의 자기 자신과 비교하는 방법입니다 (스크린샷은 가이드의 다른 이미지와 마찬가지로 가상의 디팟으로 촬영했습니다)
  • 66463이 사이트가 휴대폰 화면에 다시 들어맞습니다 — 배포 카드가 페이지를 옆으로 늘리던 문제를 해결했습니다 (카드 폭이 안에 든 긴 launchctl 명령줄에 끌려가고 있었습니다. 이제 명령줄은 자기 상자 안에서 가로로 스크롤되고, 섹션 표시 CL도 각 영역의 최신 체인지리스트로 갱신했습니다)

  • 66451휴대폰에서 좌우 비교 diff의 줄이 제자리에 맞습니다 — 한쪽 창이 눌리면서 반대쪽 줄 사이에 빈 공간이 생기던 것이 사라지고 두 창이 같은 폭을 가집니다 (표의 열 폭을 명시적으로 지정해 긴 파일 헤더가 표를 화면 밖으로 늘리지 않습니다. 줄간격을 좁히고, 좁은 화면에서는 줄번호 칸의 폭을 본문에 넘깁니다)
