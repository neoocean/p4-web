변경 이력

p4-web은 Perforce로 개발됩니다 — 아래 항목은 모두 실제로 서브밋된 체인지리스트이며 최신순입니다. 소스는 GitHub에 미러링됩니다.

2026-07-22
7일차

리뷰와 멘션, 그리고 코드가 있는 자리의 코멘트

  • 66477diff의 ---/+++ 머리 두 줄이 다시 헤더로 표시됨 — 0번 줄로 번호가 붙은 빨강·초록 편집 줄처럼 보이던 문제
  • 66476휴대폰에서 화면을 당겼을 때 배경이 바깥까지 채워지고, 옆으로 스크롤한 diff의 초록·빨강이 줄 끝까지 이어짐 (페이지 배경을 문서 루트로 옮기고, 통합 diff 행 폭을 창이 아니라 가장 긴 줄에 맞췄다)
  • 66472체인지리스트 안에서 펼친 diff가 휴대폰 화면 밖으로 파일 목록을 늘리지 않음 (셀은 표의 폭을 따르고 코드는 원래 의도대로 diff 안에서만 스크롤된다; 코멘트 패널은 스크롤해도 제자리에 남는다)
  • 66471코멘트에서 @이름을 쓰면 그 사람 상단바에 배지가 뜨고, 자신이 언급된 코멘트 목록으로 이어짐 (실제 Perforce 사용자만 인식하고 입력 중 자동완성된다; Changes 목록과 디팟 브라우저에도 체인지·파일별 코멘트 스레드 수와 미해결 수가 표시된다)
  • 66470diff 안에서 바로 그 줄에 코멘트 — 모든 diff 줄이 앵커를 갖고, 통합 보기에도 드디어 줄번호가 표시됨 (체인지리스트 diff에서 연 스레드가 해당 파일 페이지에서도 보이고 그 반대도 마찬가지다; 이미 스레드가 있는 줄에는 개수가 표시된다)
  • 66468라이트 리뷰: 체인지리스트에 리뷰 중·승인·보완 필요 상태를 달고, 누가 언제 왜 바꿨는지 이력으로 남김 (More 메뉴의 새 Reviews 페이지에서 모아 본다; 체인지리스트 자체는 아무것도 바뀌지 않고 상태는 코멘트 옆에 저장된다)
  • 66465가이드에 폴더 diff 단계 추가 — 디렉토리 전체를 다른 경로와, 또는 예전 체인지리스트·날짜 시점의 자기 자신과 비교하는 방법 (스크린샷은 가이드의 다른 이미지와 마찬가지로 가상의 디팟으로 촬영)
  • 66463이 사이트가 휴대폰 화면에 다시 들어맞음 — 배포 카드가 페이지를 옆으로 늘리던 문제 해결 (카드 폭이 안에 든 긴 launchctl 명령줄에 끌려가고 있었다; 이제 명령줄은 자기 상자 안에서 가로로 스크롤되고, 섹션 표시 CL도 각 영역의 최신 체인지리스트로 갱신했다)
  • 66462휴대폰에서는 diff가 항상 통합(unified) 보기로 나옴 — 화면이 넓어지면 “좌우 비교”가 다시 켜짐 (393 px 화면에서 코드 열이 한쪽에 130 px 남짓이라 한 줄 걸러 줄바꿈이 났다; 선택한 설정은 덮어쓰지 않고 기억하므로 태블릿을 돌리거나 창을 넓히면 두 창이 그대로 돌아온다)
  • 66458체인지리스트 안에서 연 diff가 파일 목록의 행 스타일을 물려받지 않음 — 두 창의 글자가 겹치던 마지막 경우가 사라짐 (목록 규칙이 자기 행에만 적용되도록 좁혀, 목록 행 안에 중첩된 표는 건드리지 않는다)
  • 66451휴대폰에서 좌우 비교 diff의 줄이 제자리에 맞음 — 한쪽 창이 눌리면서 반대쪽 줄 사이에 빈 공간이 생기던 것이 사라지고 두 창이 같은 폭을 가짐 (표의 열 폭을 명시적으로 지정해 긴 파일 헤더가 표를 화면 밖으로 늘리지 않는다; 줄간격을 좁히고, 좁은 화면에서는 줄번호 칸의 폭을 본문에 넘긴다)
  • 66448YAML 머리말(front matter)로 시작하는 마크다운 파일이 이제 그 부분을 깔끔한 메타데이터 표로 보여줌 — 한 문단으로 뭉개지지 않음 (이전에는 구분선 하나와 산문 한 덩어리로 렌더링되면서 first_seen_build 같은 키의 밑줄이 이탤릭으로 먹혔다; 이제 접을 수 있는 표로 나오고, 진짜 구분선으로 시작하는 파일은 그대로 둔다)
  • 66380이미지 미리보기가 가득한 페이지에서 벗어나도 Perforce 서버에 파일 리더가 남지 않음 — 취소된 다운로드가 이제 p4 print를 닫고 연결을 놓아줌 (스트리밍 리더를 정상 완료뿐 아니라 클라이언트 접속 종료 시에도 회수한다; 이전에는 남은 리더가 IDLE 연결로 쌓여 앱을 재시작하기 전까지 서버 슬롯을 붙잡고 있었다)
